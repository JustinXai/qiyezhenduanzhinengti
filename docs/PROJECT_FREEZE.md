# PROJECT_FREEZE — V1 冻结范围

## 最高产品目标

本产品不是"长报告生成器"，是一个**企业客户信任触发器**。客户在默认 Quick 报告中应在
2–3 分钟内：

1. 感觉系统真正理解他的企业；
2. 相信结论有真实证据；
3. 认为评价公平，不是在制造焦虑；
4. 知道问题影响采购、选型、咨询、试用、实施或售后中的哪个场景；
5. 看到凡间AI不仅会分析，也知道如何实施；
6. 愿意预约报告解读或获取 GEO 优化方案。

全部产品和工程决策优先判断：客户是否相信 / 看懂 / 觉得与业务有关 / 看到可实施性 /
愿意继续沟通。不得通过恶意压低分数、夸大竞品、伪造搜索结果、Evidence 错配、虚假精度、
恐吓式文案、排名/流量/线索/收入承诺促进成交。

## V1 是

- 一个独立网站；
- 一个企业诊断智能体；
- 一条非聊天式诊断流程；
- 用户提交企业资料；
- 博查负责公开网络搜索；
- 受控 Crawler 负责官网抓取；
- DeepSeek 负责结构化分析和有限 AI 问答样本；
- 系统生成结构化诊断；
- 系统渲染 Quick、Deep、Evidence 三种客户视图；
- 支持浏览器打印和 PDF 打印样式；
- 报告承接企业 GEO 优化服务。

### 用户输入

企业官网 / 品牌名称 / 所属行业 / 产品或服务 / 重点地区 / 主要竞品 /
目标客户常问的问题 / 可选补充说明 / 可选联系人和联系方式。

**联系方式只用于咨询承接，不得进入公开报告 Payload。**

## 明确不做

不接飞书 / 不接扣子 / 不接 Dify / 不做聊天机器人 / 不做多智能体产品运行时 /
不做工作流编辑器 / 不做登录、会员、支付、充值 / 不做 CRM / 不做自动内容发布 /
不做持续监测平台 / 不做六平台批量模拟 / 不做完整 GEO 内容生产系统 /
不开发销售顾问内部后台 / 不把第三方公开案例冒充凡间AI客户案例。

多个 Agent 只用于开发过程。最终产品仍然是：**单网站 + 单诊断智能体 + 单 Canonical
Report + 单诊断流程**。

Quick 和 Deep 只是阅读层级，不是用户提交时的诊断模式。用户不选择"快速分析"或
"深度分析"。系统只运行一次完整、受预算控制的诊断。
